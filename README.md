# Algebraic-variety-of-an-abelian-variety
Given an polarized abelian variety defined by its period matrix Pi=[D Z] , where D is a diagonal matrix of its polarization type and Z is the Riemann matrix associated to its polarization, all its abelian subvarieties of dimension n are in 1-1 correspondance to the rational solutions of a set of polynomial equations. This routine computes these eq.
